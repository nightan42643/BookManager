# Release 1.2.2

## 📅 Release Date
2026-03-01

## ✨ New Features

### Bookmark Health Check
- Added health check feature to detect 404 broken bookmarks
- Click the health check button to scan all bookmarks in the current folder
- Broken bookmarks are marked with a prominent red "404" badge
- Health check status persists across page refreshes
- Only truly broken (404/410) bookmarks are marked - unreachable URLs (VPN/internal sites) are not flagged
- Smart detection: if HEAD request returns 404, GET request is used to verify

## 🔧 Improvements

### Health Check Accuracy
- HEAD requests that return 404 are re-verified with GET requests (some sites don't support HEAD)
- Only HTTP 404 (Not Found) and 410 (Gone) status codes are marked as broken
- Connection timeouts and network errors are not marked (may be VPN/internal network)

### UI/UX
- Broken bookmarks display with light red background for better visibility
- 404 badge positioned in top-left corner to avoid overlap with action buttons
- Real-time progress display during health check

### Test Coverage
- Added 8 new test cases for health check functionality
- Total test cases increased to 73

# Release 1.2.2

## 📅 发布日期
2026年3月1日

## ✨ 新功能

### 书签健康检查
- 新增健康检查功能，检测 404 失效书签
- 点击健康检查按钮即可扫描当前文件夹的所有书签
- 失效书签会显示醒目的红色"404"标签
- 健康检查状态会持久化保存，刷新页面后保持
- 只标记真正失效(404/410)的书签，无法连接的URL(VPN/内网)不会被标记
- 智能检测：HEAD请求返回404时会用GET请求再次验证

## 🔧 改进

### 健康检查准确性
- HEAD请求返回404时会用GET请求重新验证（部分网站不支持HEAD）
- 只有HTTP 404（未找到）和410（已删除）状态码会被标记为失效
- 连接超时和网络错误不会被标记（可能是VPN/内网）

### UI/UX 改进
- 失效书签显示浅红色背景，更加醒目
- 404标签位于左上角，避免与操作按钮重叠
- 健康检查过程中实时显示进度

### 测试覆盖
- 新增8个健康检查功能测试用例
- 测试用例总数增至73个
