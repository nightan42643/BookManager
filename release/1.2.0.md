# Release 1.2.0

## 📅 Release Date
2026-02-28

## ✨ New Features

### Multi-Select Bookmark Management
Complete overhaul of bookmark selection with modern keyboard shortcuts, replacing the previous Edit Mode.

**Selection Methods:**
- **Ctrl/Cmd + Click**: Toggle individual bookmark selection
- **Shift + Click**: Select a continuous range of bookmarks
- **Select All Button**: Select all bookmarks in current folder
- **Clear Selection Button**: Deselect all at once

**Visual Feedback:**
- Selected bookmarks highlighted with border and checkmark icon
- Selected count displayed in batch actions bar
- Smooth transitions and hover effects

**Batch Operations:**
- **Batch Delete**: Delete multiple bookmarks simultaneously
- **Batch Drag-Move**: Drag selected bookmarks to folders
- **Batch Delete Undo**: Undo batch deletions
- **Batch Move Undo**: Undo batch moves

**Multi-Select Restrictions:**
- Batch dragging only supports moving into folders (not before/after for ordering)
- Warning message displayed if attempting unsupported operations

### Toast Notification System
All bookmark and folder operations now show elegant toast notifications at the bottom center of the screen. Delete operations are displayed with a distinctive red gradient background to emphasize their importance.

**Toast Types:**
- **Success** (Purple gradient): Add bookmark, update bookmark, move operations
- **Delete** (Red gradient): Delete bookmark, delete folder
- **Info** (Blue gradient): Undo operations
- **Warning** (Orange gradient): No undo history available, batch operation restrictions

### Undo System with Batch Operation Support
Comprehensive undo functionality that tracks up to 10 recent operations, including batch moves.

**Supported Operations:**
- Add bookmark/folder - Undo removes the item
- Update bookmark - Undo restores original title and URL
- Delete bookmark - Undo recreates the item in original position
- **Batch delete bookmarks** - Undo recreates all deleted bookmarks in their original positions
- Move bookmark/folder - Undo moves back to original location
- **Batch move bookmarks** - Undo restores all bookmarks to their original positions
- Delete folder - Undo recreates the folder and restores bookmarks

**Features:**
- Undo button in header (enabled only when history available)
- Maintains history of last 10 operations
- Visual feedback with disabled state when no history
- Automatic refresh after undo to show changes

**Limitations:**
- History cleared on page refresh
- Maximum 10 operations tracked

### Context Menu Enhancements
Right-click folder names to access enhanced context menu options.

**New Features:**
- **Create Subfolder**: Create a subfolder directly from the context menu
- **Rename Folder**: Quick rename without opening edit dialog
- **Delete Folder**: Delete folder (bookmarks moved to parent)

**Improvements:**
- Removed top "New Folder" button for cleaner interface
- Context menu now primary method for folder management
- Wider menu (180px) with better spacing

# Release 1.2.0

## 📅 发布日期
2026年2月28日

## ✨ 新功能

### 多选书签管理
对书签选择进行了全面改进，使用现代键盘快捷键，替换了之前的编辑模式。

**选择方式：**
- **Ctrl/Cmd + 点击**：切换单个书签的选中状态
- **Shift + 点击**：选择连续范围的书签
- **全选按钮**：选择当前文件夹中的所有书签
- **清除选择按钮**：一次性取消所有选择

**视觉反馈：**
- 选中的书签带边框高亮和勾选图标
- 批量操作栏显示选中数量
- 平滑过渡和悬停效果

**批量操作：**
- **批量删除**：同时删除多个书签
- **批量拖动移动**：将选中的书签拖动到文件夹
- **批量删除撤销**：撤销批量删除
- **批量移动撤销**：撤销批量移动

**多选限制：**
- 批量拖动仅支持移动到文件夹内（不支持排序的前/后位置）
- 尝试不支持的操作时会显示警告消息

### Toast 提示系统
所有书签和文件夹操作现在都会在屏幕底部中央显示优雅的提示消息。删除操作使用独特的红色渐变背景以强调其重要性。

**提示类型：**
- **成功** (紫色渐变)：添加书签、更新书签、移动操作
- **删除** (红色渐变)：删除书签、删除文件夹
- **信息** (蓝色渐变)：撤销操作
- **警告** (橙色渐变)：没有可撤销的历史记录、批量操作限制

### 支持批量操作的撤销系统
全面的撤销功能，可追踪最近的 10 个操作，包括批量移动。

**支持的操作：**
- 添加书签/文件夹 - 撤销会删除该项
- 更新书签 - 撤销恢复原标题和 URL
- 删除书签 - 撤销在原位置重新创建
- **批量删除书签** - 撤销在原位置重新创建所有删除的书签
- 移动书签/文件夹 - 撤销移回原位置
- **批量移动书签** - 撤销将所有书签恢复到原始位置
- 删除文件夹 - 撤销重新创建文件夹并恢复书签

**功能特性：**
- 标题栏中的撤销按钮（仅在有历史记录时启用）
- 维护最近 10 个操作的历史记录
- 无历史记录时视觉反馈显示禁用状态
- 撤销后自动刷新以显示更改

**限制：**
- 页面刷新后历史记录清空
- 最多追踪 10 个操作

### 右键菜单增强
右键点击文件夹名称访问增强的右键菜单选项。

**新功能：**
- **创建子文件夹**：直接从右键菜单创建子文件夹
- **重命名文件夹**：快速重命名，无需打开编辑对话框
- **删除文件夹**：删除文件夹（书签移动到父文件夹）

**改进：**
- 移除顶部"新建文件夹"按钮，界面更简洁
- 右键菜单现在是文件夹管理的主要方式
- 更宽的菜单（180px）和更好的间距
