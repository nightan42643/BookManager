# Release 1.2.1

## 📅 Release Date
2026-03-01

## ✨ New Features

### Folder Rename
- Right-click on any folder to access the rename option
- Rename operation supports undo
- System folders (Bookmarks Bar, Other Bookmarks) cannot be renamed

### Search State Persistence
- Search filter is now preserved when refreshing the page

## 🔧 Improvements

### Performance Optimization
- Improved memory efficiency when browsing large bookmark collections
- Faster rendering when switching between folders
- Reduced resource usage during drag-and-drop operations

### UI Improvements
- Custom styled prompt dialog for folder rename (replaces native browser prompt)

### Code Quality
- Added automated test coverage (65 test cases)
- Refactored event handling for better stability
- Consolidated duplicate code for easier maintenance

## 🐛 Bug Fixes
- Fixed bookmark drag-and-drop sorting undo not working correctly
- Fixed search filter disappearing after browser refresh
- Fixed potential memory leaks when repeatedly opening folders
- Improved stability during batch bookmark operations

# Release 1.2.1

## 📅 发布日期
2026年3月1日

## ✨ 新功能

### 文件夹重命名
- 右键点击任意文件夹即可重命名
- 重命名操作支持撤销
- 系统文件夹（书签栏、其他书签）不可重命名

### 搜索状态保持
- 刷新页面后搜索条件会被保留

## 🔧 改进

### 性能优化
- 改善浏览大量书签时的内存效率
- 切换文件夹时渲染速度更快
- 减少拖拽操作时的资源占用

### 界面改进
- 文件夹重命名使用自定义样式对话框（替代浏览器原生弹窗）

### 代码质量
- 新增自动化测试覆盖（65个测试用例）
- 重构事件处理以提高稳定性
- 整合重复代码以便于维护

## 🐛 问题修复
- 修复书签拖拽排序后撤销无效的问题
- 修复刷新浏览器后搜索条件消失的问题
- 修复重复打开文件夹时可能出现的内存泄漏
- 提升批量书签操作时的稳定性
