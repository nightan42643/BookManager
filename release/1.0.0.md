# Release 1.0.0

**Release Date:** 2026-02-27

## Features

- New tab page with bookmark manager interface
- Browse Chrome bookmarks with folder structure
- Add, edit, delete bookmarks and folders
- Drag & drop to move bookmarks between folders
- Real-time search by title and URL
- Bilingual interface (中文/English)
- Automatic favicon caching (24h)
- Edit mode for batch operations
- Debug mode with logging

## Tech Stack

Manifest V3 • Vanilla JS • Chrome APIs (Bookmarks, Storage, Tabs)

None
