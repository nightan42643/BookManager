# Release 1.1.0

**Release Date:** 2026-02-28

## New Features

### 🗂️ Folder Tree Navigation
- Expandable/collapsible folder tree in sidebar
- Support for 3-level depth hierarchy
- Auto-expand parent folders when selecting nested items

### 📏 Resizable Sidebar
- Drag to resize sidebar width (280-600px)
- Smooth resize animation
- Width preference automatically saved

### 📋 Enhanced Folder Management
- Right-click context menu for folders (delete, rename)
- System folders (Bookmarks Bar, Other Bookmarks) are protected from deletion
- Drag and drop folders to reorder
- Select subfolders from any top-level folder when adding/editing bookmarks

### 🔄 Drag and Drop Improvements
- Drag bookmarks to reorder within the same folder
- Drag bookmarks between different folders
- Drag folders to reorder
- Visual feedback during drag operations

### 💬 Custom Dialog System
- Beautiful custom dialogs replacing native alerts/confirms
- Smooth animations and modern design
- Better visual feedback for user actions

### 🎯 Better UX Details
- Show full bookmark title on hover when text is truncated
- Maintain search filter when switching languages
- Improved visual hierarchy with proper indentation

## Improvements

### Performance
- Smart favicon loading with batch processing
- Lazy loading for bookmark favicons
- Intelligent caching with automatic retry mechanism

### UI/UX
- Consistent and smooth animations across all interactions
- Better visual feedback for drag and drop operations
- Improved spacing and layout throughout the interface

## Bug Fixes

- 🐛 Fixed search filter being lost when switching languages
- 🐛 Fixed folder title not updating when switching language

# 版本 1.1.0

**发布日期：** 2026-02-28

## 新功能

### 🗂️ 文件夹树导航
- 侧边栏文件夹支持展开/折叠

- 选择嵌套项时自动展开父文件夹

### 📏 可调整侧边栏宽度
- 拖动调整侧边栏宽度（280-600px）
- 平滑的调整动画
- 宽度偏好自动保存

### 📋 增强的文件夹管理
- 文件夹右键菜单（删除、重命名）

- 添加/编辑书签时可选择任意顶级文件夹的子文件夹

### 🔄 拖拽功能改进
- 拖拽书签在同一文件夹内重新排序

- 拖拽过程中的视觉反馈

### 💬 自定义对话框系统
- 美观的自定义对话框替代原生弹窗
- 流畅的动画和现代化设计
- 更好的用户操作视觉反馈

### 🎯 更好的用户体验细节
- 书签标题过长时鼠标悬停显示完整标题
