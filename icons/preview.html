📋 如何使用

该图标已经创建为 SVG 矢量格式，您需要将其转换为 PNG 格式以用于 Chrome 扩展。

方法一：在线转换（推荐）

  • 访问 CloudConvert（cloudconvert.com）或 Convertio（convertio.co）
  • 上传 icon.svg 文件
  • 分别转换为 16x16、48x48、128x128 像素的 PNG
  • 下载并重命名为 icon16.png、icon48.png、icon128.png
  • 替换 icons 目录中的现有文件

方法二：使用命令行工具

如果您安装了 ImageMagick 或 Inkscape，可以使用命令行转换：

# 使用 ImageMagick convert -background none icon.svg -resize 16x16 icon16.png convert -background none icon.svg -resize 48x48 icon48.png convert -background none icon.svg -resize 128x128 icon128.png # 或使用 Inkscape inkscape icon.svg --export-width=16 --export-filename=icon16.png inkscape icon.svg --export-width=48 --export-filename=icon48.png inkscape icon.svg --export-width=128 --export-filename=icon128.png

方法三：使用图形软件

  • 使用 Figma、Adobe Illustrator 或 Inkscape（免费）打开 SVG
  • 导出为不同尺寸的 PNG 文件
  • 确保导出时保持透明背景
