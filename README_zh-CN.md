# 📚 书签管理器 Chrome 扩展

[English](README.md) | 简体中文

一个简洁、高效、美观的 Chrome 书签管理工具，以全屏新标签页的形式展示，让您的书签井井有条。

## ✨ 功能特性

- 🎯 **新标签页替换** - 每次打开新标签页即可看到美观的书签管理界面
- 🔍 **实时搜索** - 快速搜索书签标题和 URL，智能过滤
- 📁 **文件夹树导航** - 支持展开/折叠的文件夹结构，最多 3 层深度
- 📏 **可调整侧边栏** - 拖动调整侧边栏宽度（280-600px），自动保存偏好
- ✏️ **高级书签编辑** - 添加、编辑、删除书签和文件夹
- 🖱️ **拖放操作** - 拖拽重新排序书签和文件夹，带视觉反馈
- 🗂️ **右键菜单** - 文件夹右键快捷操作（删除、重命名）
- 🌍 **双语界面** - 中文和英文无缝切换
- 🎨 **优雅界面** - 现代化设计，流畅动画和自定义对话框
- 🖼️ **智能图标加载** - 智能缓存，自动重试和懒加载
- 🕐 **智能问候** - 根据时间段显示不同的问候语
- 🐛 **调试模式** - 内置开发者选项和日志系统

## 🚀 安装方法

### 开发者模式安装

1. **加载扩展**
   - 打开 Chrome 浏览器，访问 `chrome://extensions/`
   - 启用右上角的"开发者模式"
   - 点击"加载未打包的扩展程序"
   - 选择本项目文件夹
   - 完成！

2. **开始使用**
   - 打开新标签页（`Cmd+T` / `Ctrl+T`）
   - 即可看到书签管理界面

## 📖 使用指南

### 基本操作

**浏览书签**
- 左侧显示文件夹列表，包括"书签栏"、"其他书签"等
- 点击文件夹查看其中的书签
- 书签以卡片形式展示，显示网站图标、标题和域名

**搜索书签**
- 在顶部搜索框输入关键词
- 实时过滤显示匹配的书签

**添加书签**
- 点击"添加书签"按钮
- 填写标题、网址，选择目标文件夹
- 点击"保存"

**创建文件夹**
- 点击"新建文件夹"按钮
- 输入文件夹名称
- 新文件夹将创建在当前选中的文件夹下

**编辑和删除**
- 进入"编辑模式"显示所有操作按钮
- 或直接悬停在书签卡片上显示操作按钮
- 点击编辑按钮修改书签信息
- 点击删除按钮移除书签

**切换语言**
- 点击右上角的语言切换按钮（🌍）
- 或在设置中选择语言

**设置选项**
- 点击"设置"按钮打开设置面板
- 可切换界面语言
- 可开启调试模式查看详细日志
- 可清空 favicon 缓存

## 🛠️ 技术栈

- **Manifest V3** - Chrome 扩展最新标准
- **原生 JavaScript** - 无框架依赖，轻量高效
- **现代 CSS** - Flexbox 布局、CSS 变量、动画效果
- **Chrome Bookmarks API** - 管理书签数据
- **Chrome Storage API** - 本地数据存储
- **国际化支持** - 完整的双语系统

## 🔧 开发说明

### 修改代码后刷新扩展

1. 在 `chrome://extensions/` 页面找到本扩展
2. 点击刷新图标
3. 打开新标签页查看效果
4. 按 `F12` 打开开发者工具调试

### 自定义样式

编辑 `newtab.css` 可自定义界面：
- CSS 变量定义在 `:root` 中
- 修改渐变色、字体、间距等
- 调整卡片布局和尺寸

### 添加新翻译

在 `newtab.js` 的 `i18n` 对象中添加新的翻译键值对：
```javascript
const i18n = {
  'zh-CN': { key: '中文文本' },
  'en-US': { key: 'English text' }
};
```
